# Personal Landing Page

A simple, responsive personal landing page built with plain HTML, CSS, and JavaScript.

This project was created as a beginner-friendly introduction to web development, GitHub, GitHub Pages, and AI-assisted "vibe coding."

## 🌐 Live Website

**Website:** `https://YOUR-USERNAME.github.io`

Replace `YOUR-USERNAME` with your GitHub username.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Personal profile photo
- Short bio and tagline
- Five customizable links
- Light and dark mode
- Remembers the visitor's theme preference
- Automatically updates the copyright year
- No frameworks or external libraries required
- Free hosting with GitHub Pages

## 🛠 Built With

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub
- GitHub Pages

## 📁 Project Structure

```text
YOUR-USERNAME.github.io/
├── index.html
├── style.css
├── script.js
├── profile.jpg
└── README.md
```

### `index.html`

Contains the content and structure of the website, including the profile photo, name, bio, links, and theme toggle.

### `style.css`

Controls the visual design of the site, including typography, spacing, buttons, responsive layouts, and light/dark color themes.

### `script.js`

Adds interactivity to the site. It handles the light/dark mode toggle, saves the visitor's theme preference using `localStorage`, and automatically displays the current year.

### `profile.jpg`

The profile photo displayed on the landing page.

## 🚀 Running the Site Locally

No special software or development server is required.

1. Download or clone the repository.
2. Make sure all of the project files are in the same folder.
3. Open `index.html` in a web browser.

The site should load immediately.

## ✏️ Customizing the Site

Open `index.html` and replace the placeholder information with your own:

- Name
- Tagline
- Bio
- LinkedIn URL
- GitHub URL
- Instagram URL
- YouTube URL
- Email address

Replace `profile.jpg` with your own photo while keeping the filename the same.

You can customize colors, spacing, fonts, button styles, and other visual elements in `style.css`.

## 🌙 Dark Mode

The site includes a light/dark mode toggle.

When a visitor selects a theme, JavaScript saves the preference in the browser using `localStorage`. The site remembers that preference when the visitor returns.

## 📱 Responsive Design

The page is designed to work on different screen sizes.

A CSS media query adjusts elements such as padding, image size, and typography on smaller screens.

## 🚀 Deployment with GitHub Pages

This project can be hosted for free using GitHub Pages.

For a personal GitHub Pages website, create a repository named:

```text
YOUR-USERNAME.github.io
```

Upload the project files and then go to:

**Repository → Settings → Pages**

Under **Build and deployment**:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

Save the settings.

The website will then be available at:

```text
https://YOUR-USERNAME.github.io
```
